# EXPLORATION SUMMARY: Lesson Structure & Chapter Merge/Split

## Quick Reference

### 1. DATA MODEL
- **Lesson fields:** id, courseId, title, order, chapterNumber, pageRange, transcript, summary, explanation, quiz, flashcards, exercises, notes
- **Key for merge/split:** 
  - `order` (Int): Controls sequence, updated atomically
  - `transcript` (String?): Contains lesson content
  - `chapterNumber` (Int?): Can track source during splits

### 2. COMPONENT HIERARCHY
```
page.tsx (state)
  └─ LessonList.tsx (presentation)
     ├─ SortableLessonItem (dnd-kit)
     ├─ Search/filter
     ├─ Add lesson form
     └─ Re-split button (books only)
```

### 3. API ENDPOINTS (Existing)
| Method | Route | Purpose |
|--------|-------|---------|
| POST | /api/courses/{id}/lessons | Create lesson |
| PUT | /api/lessons/{id} | Update title |
| PUT | /api/lessons/{id}/transcript | Update transcript |
| DELETE | /api/lessons/{id} | Delete lesson |
| PATCH | /api/courses/{id}/lessons/reorder | Reorder all |

### 4. STATE MANAGEMENT PATTERN
```
User Action
  → Handler (page.tsx): handleXyz()
    → Optimistic update: setSelectedCourse({ ...lessons })
    → API call (async)
    → Revert on error
    → Toast feedback
```

### 5. CHAPTER SPLIT (detectChapters)
- **Input:** Raw text
- **Output:** DetectedChapter[] with title, content, wordCount, confidence, patternType
- **Patterns (priority):** keyword > lesson > markdown-h1 > roman > numbered > all-caps > dash-separator
- **Guards:** Monotonic number check, minimum content check

## NEEDED FOR MERGE/SPLIT FEATURES

### API Endpoints (New)
1. **POST /api/lessons/{id}/split**
   - Input: { splitPoints: Position[] }
   - Output: { lessons: Lesson[] }
   - Action: Split 1 lesson into N, reorder

2. **POST /api/courses/{id}/lessons/merge**
   - Input: { lessonIds: string[] }
   - Output: { lesson: Lesson }
   - Action: Merge N lessons into 1, delete originals, reorder

### Frontend Changes
1. Add merge/split buttons to LessonList UI
2. Add handlers to page.tsx: handleMergeLessons(), handleSplitLesson()
3. Optionally: Modal/dialog for split point selection

### Considerations
