| # | Verdict | Justification |

| M-20 | INVALID | Upload route (`courses/upload/route.ts` L:57-58) uses `file.type` as a file extension string (e.g. `.vtt`, `.srt`, `.txt`), NOT as a MIME type. | M-24 | INVALID | `useKeyboardShortcuts.ts` (L:14-25) `parseCombo()` correctly parses `meta`/`cmd` modifiers. The event handler (L:64) checks `combo.ctrl === (e.ctrlKey \|\| e.metaKey)`, meaning ctrl-based shortcuts also match metaKey. The `meta` parsed flag is tracked separately from `ctrl` on L:20, and the match logic at L:64-67 would compare properly. Meta shortcuts work because metaKey is checked in ctrlMatch. |

The FlashcardDeck's own handler doesn't guard for inputs, but it only uses arrow keys and space which have minimal form interference. |
| M-26 | INVALID | `ocr.ts` has NO `maxPages` parameter at all. The `ocrPdf()` function (L:84) takes only a `Buffer` and processes all pages from the PDF. There is no configurable maxPages to validate. |

## Performance & Edge Cases

| # | Verdict | Justification |
|---|---------|---------------|
| M-27 | VALID | `analytics/overview/route.ts` (L:49-52) calls `prisma.lessonProgress.findMany()` with `where: { completed: true, completedAt: { not: null } }` loading ALL completed progress records into memory. For users with thousands of completed lessons, this is unbounded. Used for both streak calculation and study frequency bucketing. |
| M-28 | VALID | `toDateString()` (L:193-195) uses `date.toISOString().split("T")[0]` which is UTC-based. Streak calculation (L:87-157) and frequency bucketing (L:162-188) both use this UTC date grouping. A lesson completed at 11pm local time in UTC+7 would show as the next day. |
| M-29 | VALID | `udemy/courses/route.ts` (L:14-15) fetches `?page_size=100` with no pagination logic — only first page returned. `data.results` is mapped directly (L:37-44). Udemy API's `next` field is ignored. Users with >100 enrolled courses will see truncated list. |
| M-30 | INVALID | `split-ai.ts` has NO retry logic. `detectChaptersWithAI()` (L:287-323) makes a single API call. The caller in `books/split/route.ts` (L:148-193) wraps it in try/catch and falls back to heuristic on failure — no retry with same prompt. The claimed `splitChaptersByAI` function doesn't exist. |
| M-31 | INVALID | `split-patterns.ts` `matchPatterns()` (L:193-313) is a single O(n) pass through lines with constant-time regex tests per line. No nested loops over lines. Each line is tested against a fixed set of regex patterns, all O(1) per line. Total complexity is O(n × k) where k is the constant number of patterns (~7). |
| M-32 | PARTIALLY VALID | `srs.ts` `calculateSM2()` (L:31-67): When `repetitions >= 2`, interval = `Math.round(interval * easinessFactor)` (L:40). If input `interval` is 0 (possible after reset), result is 0 — not Infinity/NaN, but a zero-day interval creating an infinite review loop. `easinessFactor` is floored at 1.3 (L:51-53) so NaN/Infinity from EF is prevented. The formula won't produce Infinity/NaN but CAN produce 0-day intervals. |
| M-33 | INVALID | `NotesEditor.tsx` auto-save debounce (L:173-185) returns a cleanup function that clears `debounceRef`. Search debounce (L:188-213) also returns cleanup clearing `searchDebounceRef`. Both useEffect hooks properly clean up timers on unmount via their return functions. |
| M-34 | INVALID | `AIAssistantPanel.tsx` renders AI content via `<MarkdownRenderer content={...} />` (lines 719, 1288). `MarkdownRenderer.tsx` uses `react-markdown` with `remarkGfm` and `rehypeHighlight` — this parses markdown safely into React elements, NOT via `dangerouslySetInnerHTML`. react-markdown does not render raw HTML by default. No XSS risk. |
